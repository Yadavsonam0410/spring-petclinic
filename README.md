# Pet Clinic Application
=========================

## Project Overview
-------------------

The Pet Clinic Application is a Java-based web application that provides a comprehensive solution for managing pets and their owners. The application is built using the Spring Framework and utilizes a database to store and retrieve data.

## Key Features
----------------

*   User authentication and authorization
*   Pet management (create, read, update, delete)
*   Owner management (create, read, update, delete)
*   Visit management (create, read, update, delete)
*   Specialty management (create, read, update, delete)
*   Support for multiple databases (MySQL, PostgreSQL, H2, HSQLDB)

## Tech Stack
--------------

*   Java 11
*   Spring Framework 5.3.22
*   Spring Boot 2.5.6
*   Maven 3.8.6
*   Docker 20.10.14
*   Kubernetes 1.23.5

## Installation Guide
----------------------

### Prerequisites

*   Java 11 installed on your system
*   Maven 3.8.6 installed on your system
*   Docker 20.10.14 installed on your system
*   Kubernetes 1.23.5 installed on your system

### Steps to Install

1.  Clone the repository using the following command:

    ```bash
git clone https://github.com/your-repo-link.git
```

2.  Navigate to the project directory:

    ```bash
cd pet-clinic-application
```

3.  Build the project using the following command:

    ```bash
mvn clean package
```

4.  Create a Docker image using the following command:

    ```bash
docker build -t pet-clinic-application .
```

5.  Run the Docker container using the following command:

    ```bash
docker run -p 8080:8080 pet-clinic-application
```
